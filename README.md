# 臺灣交通事故資料整合分析平台

一個純前端（無需後端伺服器）的靜態網站，整合三種官方資料來源，讓使用者可以自由篩選、交叉比對、視覺化並匯出：

1. **A1 交通事故明細**（110–114 年 / 西元 2021–2025，共 8,647 件事故、22,146 筆當事者資料）
2. **舉發統計**（108–114 年 / 西元 2019–2025，9 大類：闖紅燈、超速 40km 以下、未戴安全帽、未繫安全帶、危險駕車、違規停車、不依規定轉彎、其他原因、總件數）
3. **縣市重要統計指標**（1998–2025，人口、人口密度、道路里程、事故傷害死亡率等 16 項長期指標）

## 功能

- 側邊欄多維度篩選（年度、縣市、天候、光線、道路類別、事故類型、肇因），全站連動
- 6 大分頁：總覽 KPI／地圖（含叢集與熱力圖）／自由交叉比對／事故 vs 舉發執法／事故 vs 人口縣市／完整資料表
- 圖表匯出 PNG、地圖匯出 PNG、篩選後資料匯出 CSV / Excel、交叉表匯出 CSV
- 深色 / 淺色主題切換
- 純靜態檔案，可直接部署到 GitHub Pages、Netlify、Vercel 或任何靜態主機，也可以直接雙擊 `index.html` 在本機瀏覽器開啟使用

## 目錄結構

```
├── index.html              網站主頁面
├── css/style.css           樣式
├── js/                     前端邏輯
│   ├── util.js             共用工具（色票、格式化、匯出輔助）
│   ├── state.js             全域篩選狀態與資料存取
│   ├── charts.js             Chart.js 圖表渲染
│   ├── map.js                Leaflet 地圖
│   ├── export.js             CSV / Excel 匯出
│   └── app.js                 UI 綁定與分頁調度
├── data/                   由 build_data.py 產生的資料檔（網站直接讀取，勿手動編輯）
│   ├── accidents.data.js    事故明細（已依「當事者順位=1」去重為一列一事故）
│   ├── parties.data.js      當事者明細（可能多筆對應一件事故，用 aid 對應 accidents 的 id）
│   ├── enforcement.data.js  舉發統計（長格式：年度/縣市/類別/車種/件數）
│   ├── indicators.data.js   縣市統計指標（長格式：年度/縣市/指標名稱/數值）
│   └── meta.data.js         中介資料（年度範圍、縣市清單等）
├── data_raw/               原始資料檔（CSV / xlsx），供 build_data.py 讀取
│   ├── accidents/          A1 事故明細 CSV，檔名為西元年份，如 114.csv
│   ├── enforcement/        舉發統計 xlsx，各類別各一個檔案
│   └── indicators/         縣市統計指標 xlsx
└── scripts/
    ├── build_data.py       資料建置腳本（見下方「更新資料」）
    └── requirements.txt    build_data.py 所需的 Python 套件
```

## 如何在本機開啟

直接用瀏覽器打開 `index.html` 即可（所有資料已內嵌為 JS 檔，不需要啟動伺服器、不會有 CORS 問題）。

## 如何部署到 GitHub Pages

1. 把整個資料夾內容 push 到你的 GitHub repository（例如 repo 名稱 `traffic-dashboard`）
2. 到 repo 的 **Settings → Pages**，Source 選擇你的分支（例如 `main`）與根目錄 `/`
3. 稍待片刻，GitHub 會給你一個網址，例如 `https://<你的帳號>.github.io/traffic-dashboard/`

> 因為是純靜態檔案，之後每次更新資料只要重新 push 覆蓋 `data/*.data.js` 即可，不需要任何額外設定。

## 如何更新 / 新增資料

這是設計給你之後持續維護用的重點：**只要把新的原始檔放進 `data_raw/`，重新執行一次建置腳本即可**，不需要改任何網站程式碼。

### 1) 新增一個年度的 A1 事故明細

把政府資料開放平台下載的 CSV（欄位格式需與現有檔案相同）放進 `data_raw/accidents/`，檔名用西元年份，例如新增 115 年資料就存成：

```
data_raw/accidents/115.csv
```

### 2) 更新舉發統計

到 `data_raw/enforcement/` 底下，用新版 xlsx 直接覆蓋對應類別的檔案即可（檔名不用改，例如 `闖紅燈.xlsx`）。只要新版檔案裡有新增的年度列，腳本就會自動讀到。

### 3) 更新縣市統計指標（人口、事故死亡率等長期指標）

直接用新版本覆蓋 `data_raw/indicators/縣市統計指標.xlsx`。

### 4) 重新產生網站資料

```bash
cd scripts
pip install -r requirements.txt --break-system-packages   # 第一次執行才需要
python3 build_data.py
```

執行完成後，`data/*.data.js` 會自動重新產生，重新整理網頁（或重新部署到 GitHub Pages）就會看到新資料，年度篩選清單也會自動包含新年度，不需要改程式碼。

若原始檔的欄位名稱或格式有變動（例如政府資料平台改版），`build_data.py` 內有詳細註解說明每個資料來源的解析邏輯，可以直接請 Claude（或熟悉 Python 的人）協助調整。

## 資料處理備註

- 事故明細原始 CSV 是「一列一位當事者」，本站已依「當事者順位＝1」的列取出「一列一件事故」的事故層級欄位（天候、地點、死傷人數等），當事者層級的欄位（車種、性別、年齡等）保留在 `parties.data.js` 中，用 `aid` 對應回事故的 `id`。
- 事故發生地點的縣市是用地址字串比對「發生地點」欄位開頭的縣市名稱取得（因原始資料的「處理單位」欄位對於國道公路警察局、港務警察、鐵路警察等單位無法直接對應到單一縣市）。
- 舉發統計與縣市統計指標的歷史縣市名稱（如臺北縣、桃園縣、高雄縣市改制前）已正規化合併到現行 22 縣市。
- 「事故 vs 舉發執法」分頁比對時，僅取事故資料（110–114）與舉發資料（108–114）的重疊年度。
- 「事故 vs 人口/縣市」分頁的長期趨勢圖使用官方統計指標原始年度範圍（1998–2025），不受年度篩選限制。

## 資料來源

- 內政部警政署 A1 交通事故資料
- 內政部警政署舉發交通違規統計
- 內政部縣市重要統計指標
